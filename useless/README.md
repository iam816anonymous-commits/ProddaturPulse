# Registration storage (placeholder)

This folder is reserved for Proddatur Pulse registration exports.

**Do not put real visitor names, phone numbers, or other personal information in this folder while the repository is public.** Files committed here are publicly readable.

The public GitHub Pages form cannot safely write files into this repository by itself. A secure authenticated submission mechanism and private storage configuration are required before live registrations can be saved here.

No real registrations are stored in this folder.
